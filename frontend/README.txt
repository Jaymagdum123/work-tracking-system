TECHNOLOGIES
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

HOW TO RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. On the login page, click Sign In.
5. Explore Dashboard and all modules from the sidebar.

This package is connected to a Flask + MySQL backend. Start the backend and open http://127.0.0.1:5000/ .
